# Ruta Escáner

App web para escanear direcciones de etiquetas, numerarlas (0001, 0002…), optimizar la ruta con Valhalla (gratis, sin clave) y verla en un mapa con calles (OpenStreetMap).

- Lectura de la foto con Gemini (clave propia, opcional) o en el teléfono (Tesseract).
- Las claves y las paradas se guardan solo en el navegador del teléfono.
- Se publica gratis con GitHub Pages desde la rama `main`.
